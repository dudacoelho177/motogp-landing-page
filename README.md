# MotoGP Landing Page

Landing page estática temática de MotoGP, com foco em velocidade, adrenalina e informações sobre a categoria.

## Visão geral

Este projeto foi desenvolvido com HTML, CSS e JavaScript para criar uma página inicial moderna e responsiva, inspirada no universo da MotoGP. A página apresenta:

- Hero section com mensagem principal
- Destaque visual para a imagem de um piloto famoso
- Botão interativo para exibir uma curiosidade
- Seção "Sobre a MotoGP"
- Cards com informações da categoria
- Layout responsivo para desktop e mobile

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- [index.html](index.html): estrutura da página
- [style.css](style.css): estilos visuais e responsividade
- [script.js](script.js): interação do botão de curiosidade
- [img](img): imagens utilizadas na landing page

## Como executar

### Opção 1: abrir diretamente no navegador

1. Abra o arquivo [index.html](index.html) em um navegador.
2. A página será carregada normalmente.

### Opção 2: executar um servidor local

No terminal, na pasta do projeto, execute:

```bash
python3 -m http.server 8000
```

Depois abra no navegador:

```bash
http://localhost:8000
```

## Funcionalidades

- Layout com tema esportivo e visual premium
- Texto principal com chamada forte para a MotoGP
- Botão "Mostrar curiosidade" com interação em JavaScript
- Interface responsiva para diferentes tamanhos de tela
- Efeito de overlay na imagem ao passar o mouse
